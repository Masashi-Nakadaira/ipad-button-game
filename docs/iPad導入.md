# iPadへの導入とオフラインでの遊び方

このページは、iPadにゲームを入れて、あとからネットにつながずに遊ぶための手順です。専用ページは[こちら](https://Masashi-Nakadaira.github.io/ipad-button-game/)です。ログイン不要の公開ページです。MacとiPadが同じWi-Fiに接続している必要はありません。

## 最初の導入

1. iPadをインターネットにつなぎ、Safariで[HTTPS専用ページ](https://Masashi-Nakadaira.github.io/ipad-button-game/)を開きます。ホーム画面アプリの初回導入にはこのURLを使います。`http://<MacのIPアドレス>:8787` は同じWi-Fiでオンライン試遊するためのLAN URLです。
2. Safariの共有ボタンから「ホーム画面に追加」を選びます。必要なら「その他」を開き、「Webアプリとして開く」をオンにして追加します。
3. ホーム画面にできた「ボタンゲーム」のアイコンをタップします。初回はオンラインのまま開き、ホームまたは設定に「オフラインで遊べる準備ができました」と表示されるまで待ちます。ページやゲームの保存中は少し時間がかかることがあります。
4. ホーム画面のアプリをいったん終了します。機内モードにしてから、同じホーム画面アイコンで起動し、ゲームを開いて遊べることを確認します。

Safariで準備完了を見ただけでは、ホーム画面アプリの準備ができたことにはなりません。iPadOSではホーム画面アプリとSafariでCookieやWebサイトの保存領域が別になるため、必ずホーム画面のアイコンから一度オンラインで開いて準備を完了してください。Safariで以前遊んだ記録がホーム画面アプリへ自動で移ることも保証されません。

Appleの案内: [iPadのSafariでWebサイトをアプリにする](https://support.apple.com/guide/ipad/ipad8f1f7a29/ipados)、[WWDC23「Webアプリの新機能」](https://developer.apple.com/jp/videos/play/wwdc2023/10120/)。Service Workerには安全なコンテキストが必要です。詳しくは[MDNのServiceWorkerContainer.register()](https://developer.mozilla.org/en-US/docs/Web/API/ServiceWorkerContainer/register)を参照してください。

## オフラインで使える機能

一度ホーム画面アプリで準備を完了すると、タッチ操作と、iPadに接続済みの対応Bluetooth HIDキーボードで単体プレイできます。ゲーム本体と音楽はアプリに含まれています。読み上げはiPadに利用可能な音声がある場合に使われ、音声が使えない場合は画面の合図に切り替わります。

Wi-Fiコントローラーを使うときは、Nodeサーバーを起動し、iPadでもSafariから `http://<MacのIPアドレス>:8787` を開いてください。HTTPSホーム画面アプリは同一originのAPIだけを検出するため、Nodeサーバーを同じWi-Fiに置くだけでは入力を中継できません。HTTPSホーム画面版からNodeサーバーへの外部LAN中継接続は未対応です。スマートフォンやESP32からの入力も、このLAN URLで開いたゲーム画面を通して使います。Safariから一般的なBluetooth GATT機器へ直接接続する機能はありません。

記録はブラウザーごと、ホーム画面アプリごとに別々に保存されます。また、従来のHTTPページで遊んだ記録は新しいGitHub PagesのURLへ自動移行しません。以前のHTTPSページからも自動移行しません。公開URLをSafariで開き、ホーム画面に追加し直してください。旧記録が必要な場合は旧アイコンと旧Webサイトデータを残してください。SafariのWebサイトデータやホーム画面アプリの保存領域を消去すると、オフライン用データやその場所に保存した記録も消えることがあります。

## 更新する

新しい版がオンラインで利用できると、Homeまたは設定に「新しい版を使えます」と表示されます。プレイ中はゲームを終えてHomeに戻ってから「いま更新する」をタップしてください。更新後に「オフラインで遊べる準備ができました」と表示されれば、新しい版の保存も完了です。

## iPad実機について

Playwright WebKitでの確認は、実機iPadのSafariやホーム画面アプリでの確認とは異なります。iPad実機での導入・機内モード・Bluetoothボタン・音声・ホーム画面の全画面表示は未確認です。
